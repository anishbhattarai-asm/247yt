      OBS live input

      Go live from OBS through the panel. When OBS starts streaming it takes over the broadcast; when it stops, the playlist carries on where it left off. Same broadcast, no stream key to share, nothing to fight over.

      Server for OBS
      —
      In OBS: Settings > Stream > Service Custom. Paste this as Server and leave Stream Key empty. It includes the password, so only share it with people who may go live.

        More platforms

        Send the same stream to Twitch, Kick, Facebook or any RTMP server at the same time. Each platform connects and reconnects on its own, and adds about 3 Mbps of upload (around 1 TB a month; Oracle's free allowance is 10 TB).

        Weekly reconnect

        The connection to YouTube is renewed every few days at a quiet hour (FFmpeg's timestamps run out after ~24 days). Viewers don't notice.

        Terminal

        A command line on your server, right here: update the panel, restart things, look at files and disk space. It has full control (sudo works, like SSH), so it has its own password, asked every time it opens. Every session is reported in Discord.

          Make it different from the panel password: someone who learns that one still can't open a shell. Forgot it? On the server: node cli.js set-terminal-password
